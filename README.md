🧠 Mental Health Prediction System

A machine learning project that predicts a Mental Health Score from
student demographic, academic, social-media usage, stress, sleep, and
lifestyle information.

The project includes an end-to-end ML workflow:

Data Analysis → Data Cleaning → Feature Engineering → Preprocessing
Pipeline → Model Training → Model Evaluation → Model Serialization →
FastAPI Backend → Streamlit Frontend → Cloud Deployment
